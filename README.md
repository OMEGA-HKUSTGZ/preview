# preview

Drafts under review, served at <https://omega-hkustgz.github.io/preview/>. Nothing here is an
official OMEGA Lab page, and search engines are asked not to index it.

Each directory is the built site of one open pull request (for example `site-pr-18/` for
pull request 18 of the lab site). It is written by the shared
[`publish-preview`](https://github.com/OMEGA-HKUSTGZ/.github/tree/main/actions/publish-preview)
action and removed when the pull request closes.

Only CI writes to this repository. Do not edit it by hand: change the pull request instead.
