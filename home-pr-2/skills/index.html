共享 Skill 目录

3 组、6 个 skill，来自 lab-skills。让自己的 agent 装上就能用；装法见仓库的安装说明。

review-toolsv0.3.0

审稿：期刊与会议论文评审、修改稿核对。

  • journal-reviewresearch

    评审期刊稿件：贡献、实验是否充分、可复现性和录用建议，输出可直接填进审稿系统的意见。

  • conference-reviewresearch

    评审会议投稿：新颖性核对、逐条意见和最终自查，支持一次处理多篇。

  • revision-auditresearch

    对照上一轮意见和回复信，逐条核对修改稿是否真的改了。

meeting-toolsv0.2.0

会议：从逐字稿整理纪要和待办。

  • meeting-minutesresearch

    把会议逐字稿整理成纪要：按议题归类，列出决定和带责任人的待办。

  • voice-transcribemlops

    把录音转成带时间戳的文字，需要自己配置语音识别后端。

progress-toolsv0.1.0

进展：把讨论整理成进展记录并提交。

  • progress-submitresearch

    把一次讨论或一周的工作整理成进展记录，检查通过后提交到自己方向的仓库。
